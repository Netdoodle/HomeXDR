## HomeXDR v0.1.2 (beta)

Syslog intake now understands more firewalls. It is still a beta: read the known
limitations below before you rely on it.

### What's new

- **More firewall logs.** Syslog decoders for FortiGate, Palo Alto, Sophos, MikroTik and
  Ubiquiti (UniFi gateways and EdgeRouters), plus generic CEF and LEEF. Traffic events are
  normalised to pass or block, keep the vendor's own action word, and get a Community ID so
  they join to endpoint processes like OPNsense and pfSense logs already do. Detections,
  the device inventory and the exposure view read them too.
- **Choose a parser per sender.** In Settings → Integrations, admins can bind each syslog
  sender to a parser (auto-detect stays the default), including pfSense, which looks the
  same as OPNsense on the wire, or plain syslog with no decoding. A line the chosen parser
  can't read falls back to auto-detection. Changes are saved and audited.
- **Live demo and README screenshots**, and issue templates for bug reports.
- **Vulnerabilities.** Clickable summary tiles, a field-aware search and a per-group
  switch for vulnerability management.
- **Defender card** shows the last quick and full scan times.
- **Dependency updates** for vitest and OpenTelemetry (security fixes).
- The compose files and `.env.example` now default to this version.

### Upgrading

Back up the `data` volume (and ClickHouse's) first. Then:

```bash
git fetch --tags && git checkout v0.1.2
cd deploy && docker compose pull && docker compose up -d
```

### Known limitations

- **New firewall decoders** are tested against sample lines, not yet against real devices.
  If one misreads your logs, bind that sender to plain syslog and open an issue with a
  sanitised sample.
- **Unsigned agents.** Windows may show a SmartScreen warning for the agent.
- **Open security review findings**, listed in the
  [roadmap](https://github.com/Netdoodle/HomeXDR/blob/v0.1.2/docs/roadmap.md).
- **Not yet reviewed:** the network sensors, software inventory, enrollment and self-update
  code in the agent, and syslog and NetFlow intake.

### Reporting a security issue

Please report vulnerabilities privately, as described in
[SECURITY.md](https://github.com/Netdoodle/HomeXDR/blob/v0.1.2/SECURITY.md), not in a public issue.
