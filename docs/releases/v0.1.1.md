## HomeXDR v0.1.1 (beta)

The first update after v0.1.0. It is still a beta: read the known limitations below before
you rely on it.

### What's new

- **Two-factor login and HTTPS.** Optional authenticator-code login with recovery codes and
  an admin reset, and built-in HTTPS for the console (a HomeXDR CA or your own certificate
  files, with an optional redirect). The v0.1.0 notes listed both as missing.
- **Host actions menu.** Reboot, shut down, restart the agent, fetch agent logs, flush the
  command queue, list applications, rescan and remove a host. Destructive actions ask for
  an authenticator code. Kill process now lets you pick from the host's running processes.
- **Alert storyline.** A graph of an alert's attack chain, with cross-process links,
  scheduled-task, service and WMI launches and ATT&CK tactics per process. Big branches
  open a few children at a time. Windows agents turn on the Sysmon events it needs, per
  group.
- **Detection.** Threshold and correlation rules (Sigma `count()` and correlation rules),
  16 new macOS rules, and decoy files on every agent with paths you choose in the console.
- **Vulnerabilities.** A full CVE review page with a risk score, and affected-version
  ranges that settle false matches.
- **macOS agent.** Login items from Background Task Management, a DNS sensor, and Full Disk
  Access that survives agent updates.
- **Health.** Offline hosts and sources are labelled by what they are, and the DNS query
  log shows as a source rather than a host.
- **Security fixes from a November review.** Install commands check the script's SHA-256
  before running it, sign-in and two-factor limits hold under parallel requests, expired
  agent certificates renew only close to expiry, and backup import verifies each archive
  before inserting anything.
- A new icon set.

### Upgrading

Back up the `data` volume (and ClickHouse's) first. Then:

```bash
git fetch --tags && git checkout v0.1.1
cd deploy && docker compose pull && docker compose up -d
```

### Known limitations

- **Unsigned agents.** Windows may show a SmartScreen warning for the agent.
- **Open security review findings**, listed in the
  [roadmap](https://github.com/Netdoodle/HomeXDR/blob/v0.1.1/docs/roadmap.md): Linux
  suppression labels that a local user can set, the Windows program-data folder when
  someone else creates it first, the executable hash cache, and one file-event rate limit
  for every path.
- **Not yet reviewed:** the network sensors, software inventory, enrollment and self-update
  code in the agent, and syslog and NetFlow intake.
- **New host actions** have had limited testing on real machines. Try them on a test host
  first.

### Reporting a security issue

Please report vulnerabilities privately, as described in
[SECURITY.md](https://github.com/Netdoodle/HomeXDR/blob/v0.1.1/SECURITY.md), not in a public issue.
