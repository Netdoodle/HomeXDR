# Security policy

HomeXDR runs with full privileges on every host it protects, so security reports are
welcome and handled first.

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Please do not open a public issue for it.

Include what you found, how to reproduce it, the version (`homexdr-server version` and
`homexdr-agent version`), and the platform. You should get a reply within a week.

## Supported versions

HomeXDR is in beta. Fixes go into the latest release only.

## Scope

In scope: the server, the console, the agents, the install scripts and the published
container images. Known open findings are listed in [docs/roadmap.md](docs/roadmap.md)
under "Security reviews"; reports that add to them are still welcome.
